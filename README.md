Project Portofolio: "Aplikasi WEB Kedai Foto Kopi" yaitu Landing Page & Katalog Produk UMKM
 * Deskripsi Singkat: Website profil dan katalog interaktif untuk membantu kedai kopi lokal memperluas jangkauan pemasaran mereka secara digital.
   
 Masalah (The Problem)
 * Kondisi Awal: UMKM "Kedai Foto Kopi" sebelumnya hanya mengandalkan media sosial biasa untuk berjualan.
 * Kendala Utama: * Pelanggan kesulitan melihat daftar menu lengkap beserta harga terbarunya secara rapi.
   * Tidak ada fitur order-to-WhatsApp yang otomatis, sehingga proses pemesanan manual memakan waktu lama dan sering terjadi salah catat pesanan.
   * Tampilan informasi jam operasional dan lokasi sering terlewat oleh pelanggan baru.
     
 Solusi (The Solution)
 Sebagai front-end developer, aku membangun sebuah landing page yang mobile friendly, interaktif, dan mudah diakses. Beberapa langkah pengembangan yang aku lakukan:
 * Desain Responsif (Mobile-First): Menggunakan CSS Flexbox dan Grid serta Tailwind CSS agar tampilan website tetap rapi dan nyaman dibuka lewat smartphone maupun laptop.
 * Katalog Interaktif: Menambahkan fitur filter kategori menu (Kopi, Non-Kopi, Makanan Ringan) menggunakan JavaScript DOM Manipulation agar pengguna bisa mencari menu dengan cepat.
 * Tombol Pesan Otomatis (WhatsApp Integration): Membuat tombol "Pesan Sekarang" pada setiap produk yang secara otomatis memformat pesanan ke dalam teks chat WhatsApp pemilik kedai.
 * UI/UX Sederhana & Bersih: Menggunakan palet warna yang hangat (nuansa kopi) untuk menciptakan kesan estetis dan ramah pengguna.
   
 Hasil & Dampak (The Result)
 * Peningkatan Efisiensi: Proses pemesanan pelanggan menjadi lebih cepat dan terstruktur karena format pesan otomatis mengurangi kesalahan komunikasi.
 * Pengalaman Belajar Bagiku: * Berhasil menguasai dasar-dasar Responsive Web Design dan mengatasi masalah layout yang pecah di layar kecil.
 * Memahami cara mengintegrasikan interaksi JavaScript sederhana dengan elemen HTML secara dinamis.
 * Peningkatan Portofolio: Website ini kini menjadi salah satu project andalan di GitHub-ku yang membuktikan kemampuanku mengubah wireframe desain menjadi kode fungsional.
   
 Tech Stack yang Digunakan
 * HTML5 untuk struktur kerangka web.
 * Tailwind CSS untuk styling dan membuat desain responsive.
 * JavaScript (ES6+) untuk logika interaktif (filter menu & integrasi WhatsApp).
 * Git & GitHub untuk manajemen versi kode.
